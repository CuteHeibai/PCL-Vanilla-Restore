# 独立原版下载引擎（r4）

主窗口右下角“独立原版下载”始终可用，打开独立窗口即可选择正式版、预览版、远古版本，搜索版本号，自定义安装名和游戏目录。仅安装原版，不提供组合组件或整合包安装。完成后返回 PCL 启动页刷新版本列表。游戏目录默认 EXE 同目录的 `.minecraft`，外部游戏目录需要自行选择。

## 更新时如何选择

| 官方新版变化 | 处理 |
| --- | --- |
| 原下载页与基础接入都兼容 | 恢复 PCL 原下载页，独立入口同时保留 |
| 原下载页不兼容，基础接入兼容 | 保留官方原下载页代码，主窗口接入独立引擎；记录 independent 模式 |
| 基础启动/路径/更新接入也不兼容 | 拒绝安装，当前可用 EXE 及其独立引擎继续保留 |

基础接入采用独立的严格契约，没有为了备用模式放松启动、便携路径或更新事务的校验。备用成品也携带适配引擎，后续可继续更新；官方结构重新兼容时可恢复原生模式。测试的结构变化是合成样本，不是尚未发布的未来官方版本。

## 文件和数据

读取 [Mojang 官方版本清单](https://piston-meta.mojang.com/mc/game/version_manifest_v2.json)，按元数据原始 URL、SHA1 和大小处理：

- 客户端 JAR 与标准版本 JSON。
- Windows 库、按顺序应用的操作系统/架构规则、现代 native artifact 及旧版 classifiers。
- 资源索引与 objects；旧版 virtual 与 map_to_resources 映射。
- 日志配置与纯原版 PCL 组件管理清单。

只允许已使用的 Mojang/Minecraft 官方 HTTPS 域名，重定向后再次验证来源。文件在临时目录下载并校验，通过后才复制到游戏目录；已有正确文件可复用，错误哈希会阻止安装。最多并行处理 8 个文件，网络错误有限重试；不实现 HTTP 分段续传。

引擎、窗口均在内嵌运行库中，不增加分发文件。安装暂存位于 EXE 同目录 `PCL/Cache/Vanilla`，不向系统 Temp/AppData 回退。实际游戏文件位于用户选择的目录。名称拒绝路径穿越、Windows 保留名称和非法字符；已有同名版本不覆盖。

版本全部准备完毕后，同盘以目录移动一次发布；跨盘以独占创建新目录、跟踪自己创建的文件、锁定并刷新元数据的方式完成。跨盘安装期间，原生启动器可能暂时把正在完成的目录视为无效；完成后须刷新版本列表。普通失败/取消会清理本次未完成版本，完整共享依赖可保留复用。突然断电或进程被强制终止不在恢复保证范围内。

本引擎不读取账号令牌、不更换 Client ID、不负责 Java 下载或游戏认证；登录、Java 选择和启动仍由官方 PCL 流程负责。新的 Mojang 元数据或基础 PCL 接入若发生不支持的变化，会报告失败，不跳过校验。

## 验证入口

完整构建包含独立引擎夹具测试。真实下载与安装探针：

```powershell
powershell.exe -NoProfile -NonInteractive -File tests/VerifyIndependentInstall.ps1 -VersionId 26.3 -Name Independent-26.3
```

默认仅使用仓库内 `artifacts/qa-full/.minecraft` 测试目录。测试使用全新名称，已有同名版本会拒绝。正式版、预览版、旧版、真实 GUI 与启动结果见 [verification.md](verification.md)。
